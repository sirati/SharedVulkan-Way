# HyperLinux coordinator source checkpoint

These scripts preserve the coordinator build, realized-source preflight, receipt-bound native matrix, and extracted-production contract procedures from 2026-10-20. They retain local evidence paths and exact artifact identities for reproducibility. The native batch requires an explicit `HL_REMOTE_TARGET`; it is not a general deployment command.

The verified 90ac656d runtime passed the primary permission, real-kqueue lifecycle, cleanup, alias, seccomp and signal cases. Its native batch failed ptrace completion, three DC ZVA permission/control cases, and the final seqpacket sender-exit case. These failures remain acceptance blockers. The generated matrix references that precise intermediate artifact and must not be relabeled as final.

The c1487e9e successor adds VFS directory FD authority and builds successfully. Its actual-source portable VFS helper plus unpinned negative control pass, and the real-F_GETPATH Darwin helper builds. Native VFS execution remains pending. It still contains the known 90ac failures.

Evidence, binary artifacts, output GC roots, and full logs remain outside this repository under the original evidence directory. This source checkpoint does not include test binaries or claim product, Firefox, or complete sandbox acceptance.

Inactive Pulse original-pool experiments

These fixtures load the actual Darwin libpulsecommon selected by PULSE_PACKAGE.
FIXTURE_ROOT must name a private evidence directory. Run only under the existing
headless runtime scope and exclusive runtime lease. They do not activate services
or access hardware. Do not treat fixture sources as successful runtime evidence.

origin-regression.py tests immutable origin, same-object localization, actual
strict pstream failure, zero socket bytes, and recycled block constructors.
lease-backend-regression.py tests explicit orphan/quarantine APIs, reentrant
teardown, allocator/vacuum stability and bounded whole-pool reservations.
object-death-regression.py tests original native backing after producer death.
It does not prove HyperLinux producer death or absence of surviving child writers.
fifo-eof-diagnosis.py compares the accepted earlier provider with PULSE_PACKAGE.
Its reference store path is historical evidence, not a portable dependency.

original-pool-forwarding.patch is an incomplete WIP applied after the existing
Darwin, strict-origin and backend patches. The packaged provider does not include
it, and packaged session configuration does not enable its capability. Explicit
listener and client opt-ins describe one trusted native UID with whole-pool
O_RDWR authority. SRB is forbidden. No cross-user confinement is claimed.

Protocol lifecycle tests are still needed for failed registration followed by an
already-buffered frame, live destination/source disconnect, exact release routing,
alias and exporter ID collisions, quota refusal and zero socket payload. No actual
Linux-to-native-to-Linux foreign-pool audio forwarding proof exists yet.
